	- [x]  코드 재구성 및 줄바꿈 제거
	- [x]  람다 함수 분리 및 간소화
	- [x]  Visual Studio 재시작
	- [x]  프로젝트 설정에서 문자 집합 옵션 변경
	- [x]  새 파일 생성 후 코드 복사
	- [x]  다른 인코딩으로 저장 시도 (UTF-8 with BOM)

    `fix: Server Korean Encoding`

    Visual Studio에서 C++ 코드의 인코딩 처리 방식이 상당히 까다로웠다.  
    이로 인해 `.editorconfig` 파일의 중요성을 알게 되었고,

### 🧵 스레드 생성 및 실행 문제

- **원인 분석**

- **최종 해결 방법**

  - [x] 세션 참조를 weak_ptr로 관리하여 종료된 세션 접근 방지

	 3.  세션 컬렉션을 weak_ptr로 관리하여 삭제된 세션 참조 문제 방지

    세션 참조를 `weak_ptr`로 변경하고, 브로드캐스트 시 세션 목록을 복사하여 잠금 없이 메시지 전송
- **느낀 점**  
    멀티스레드 환경에서 공유 자원 접근 시 잠금 범위와 참조 방식이 중요함을 배움.  
    단순히 잠금을 확장하는 것보다 잠금 최소화와 복사를 통한 안전성 확보가 성능상 유리함.
